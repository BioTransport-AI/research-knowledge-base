# BioTransport AI

Shared research coordination for [BioTransport AI](https://biotransportai.com) — Claude Code
skills and dated snapshots of the team's live funding & data tracker.

## Getting started

1. Clone this repo.
2. Open it in Claude Code — the skills in `.claude/skills/` load automatically.
3. Read `CLAUDE.md` for team context, standing rules, and where the live tracker doc lives.

## What's here

- `.claude/skills/` — BioTransport-AI-specific Claude Code skills
- `tracker-snapshots/` — dated PDF exports of the live research tracker (a backup, not the
  source of truth — see `CLAUDE.md` for the live doc)
