# CP-AnemiC (Conjunctival Pallor Dataset)

**Condition:** Anemia · **Modality:** Conjunctiva images
**Source:** [Mendeley Data](https://data.mendeley.com/datasets/m53vz6b7fx/1) (DOI: 10.17632/m53vz6b7fx.1)
**License:** CC BY 4.0, confirmed on the source page. This is the most clearly open-licensed
dataset in this whole list. If the team ever wants an actual copy committed somewhere (not this
git repo, still too indiscriminate a place for image data, maybe a cloud bucket instead), this is
the one with the least licensing risk.
**Size:** 710 images (children aged 6–59 months, 10 hospitals in Ghana), labeled with hemoglobin
(Hb) values. Small, on the order of tens of MB.

## No fetch script yet

Mendeley's download button doesn't expose a stable URL I could confirm without a browser session.
Visit the link above and use "Download All" manually into `data/cp-anemic/`. If someone finds the
actual direct-download URL pattern, a `fetch.sh` here would be a quick, low-risk add given the
confirmed CC BY 4.0 license.
