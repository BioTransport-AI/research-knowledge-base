# Messidor-2

**Condition:** Diabetes · **Modality:** Fundus images
**Source:** [ADCIS](https://www.adcis.net/en/third-party/messidor2/)
**Size:** 1,748 images (874 examinations, two eyes each)

## No fetch script — manual academic registration required

ADCIS gates this behind a short registration confirming academic/research use; there's no stable
unauthenticated download URL to script against. Visit the link above, register, and download
manually into `data/messidor2-diabetes/` (create that folder locally — it's gitignored, same as
every other dataset here).
